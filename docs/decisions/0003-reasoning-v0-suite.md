# 0003 — First suite: controlled Horn-rule micro-worlds, with the dataset pinned in the protocol

**Choice.** `suites/reasoning_v0` evaluates exclusive-choice questions ("which entity is
X?"). These are generated by `metanoia_research.data.microworld` and have exact labels,
proofs and depth annotations. Splits are assigned by world, and depth 4 is held out
for test. `protocol.toml` pins the content hashes of the cases and labels in a
`[dataset]` table. There is no separate `data_manifest.json`, so the whole protocol is
one hashed file.

**Shortcut controls.** Both were added after a cue was seen in the first samples:
- every candidate has the same number of facts, so mention counts reveal nothing;
- every fact's predicate appears in some rule, so padding cannot mark a distractor.

The lexical-overlap fixture therefore scores exactly chance, and a test checks this.

**Limitations.**
- Unary predicates only, so there is no role binding (H2) yet.
- No negation or "unknown" outcome.
- Three synthetic template families.

**Observed.** With the hashed-token encoder, the direct scorer overfits the training
split and stays at chance on dev and test. Its temperature fit also reaches the upper
search bound. This is an early Stage-1 observation, not a promoted result: there is
one seed, no tuning, and no pretrained encoder.

**Revisit when** Stage 3 needs multi-premise role binding, or when a realistic,
independently labeled dataset is added. Either one requires a new suite revision.
